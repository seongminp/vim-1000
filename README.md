# Vim 1000

Learn Vim through 1,011 editing challenges. Works offline.

```sh
python3 -m http.server 8080 --directory dist
```

Open [localhost:8080](http://localhost:8080), or open `dist/vim-1000-offline.html` directly.

### Prompt used to generate this website?

> Make a super good web app to learn Vim. the core experience should be that the user should be given a mission to edit a text a certain way. Maybe before and after is shown. And when the user edits, the key strokes should be visible. After they submit, we show the more idiomatic way (if any) to achieve the designated task.
>
> The success of this app lies on how well and intuitively we show the text editing task to the user. If the user spends too much time on understanding the supposed edit task, it is a failed app. It should be intuitive above all. Consult the curriculum in Practical Vim book if you need guidance on the course material. BUT DON'T COPY ANYTHING OVER!! Be original in any quizzes you create. It should be fun, no frills, and cover a lot of vim. Make sensible decisions.
>
> Make the app feel fun like Duolingo. But don't blatantly copy duolingo obviously. I mean make it good like them not copy them.

### Is this exactly the same as Vim?

It supports core Vim editing and a simulated multi-file workspace. Pattern exercises use native Vim syntax.
